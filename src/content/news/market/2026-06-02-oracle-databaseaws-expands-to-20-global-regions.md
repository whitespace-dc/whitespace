# Oracle Database@AWS Expands to 20 Global Regions

Oracle and AWS have expanded Database@AWS to 20 global regions, adding eight new locations to their multi-cloud offering. The expansion increases Oracle database availability across a broader geographic footprint on AWS infrastructure. Enterprise customers now have access to Oracle database capabilities in more strategic global locations.

# 甲骨文資料庫@AWS 擴展至 20 個全球地區

甲骨文與 AWS 擴展 Database@AWS 多雲供應方案至 20 個全球地區，新增八個地點。此擴展為企業客戶在 AWS 基礎設施上提供更廣泛的地理涵蓋範圍。甲骨文資料庫現已於更多全球戰略位置提供。
