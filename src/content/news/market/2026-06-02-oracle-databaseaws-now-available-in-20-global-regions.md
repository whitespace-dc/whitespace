# Oracle Database@AWS now available in 20 global regions

Oracle and AWS have expanded their collaborative database offering to 20 global regions, adding eight new deployment locations. The Oracle Database@AWS service, part of the companies' multi-cloud strategy, now provides broader geographic coverage for customer database workloads. This expansion enables organizations to deploy Oracle Database in more locations closer to their operations.

## 中文

# Oracle Database@AWS 現支援 20 個全球區域

Oracle 與 AWS 已將其協作資料庫服務擴展至 20 個全球區域，新增 8 個部署位置。Oracle Database@AWS 是兩家公司多雲端策略的一部分，為客戶的資料庫工作負載提供更廣泛的地理覆蓋。此次擴展使組織能在更多地點部署 Oracle 資料庫，更接近其營運據點。
