  Nvidia's Vera CPU is straining supply of LPDDR memory — a low-power memory standard developed for smartphones — as AI server deployments begin competing for components traditionally reserved for the mobile industry, according to DigiTimes Asia.

  ## Why this matters

  LPDDR, or Low Power Double Data Rate memory, is the dominant memory type in mobile phones. Its appearance in AI server infrastructure signals that hyperscale and AI compute demand is now drawing on supply chains not historically sized for data center volumes, a dynamic that can create allocation pressure across both the mobile and server markets.
