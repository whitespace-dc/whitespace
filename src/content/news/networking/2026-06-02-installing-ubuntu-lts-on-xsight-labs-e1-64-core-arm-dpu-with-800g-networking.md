# Installing Ubuntu LTS on Xsight Labs E1 64-Core ARM DPU with 800G Networking

ServeTheHome documents the installation of Ubuntu LTS on the Xsight Labs E1, a 64-core ARM Neoverse N2 DPU with 800Gbps networking and PCIe Gen5 support. The installation demonstrates that the E1 can run vanilla Ubuntu without proprietary modifications. This highlights the feasibility of deploying standard Linux on this advanced data center DPU.

# Xsight Labs E1 64核Arm DPU 安裝 Ubuntu LTS

ServeTheHome 記錄在 Xsight Labs E1（64核Arm Neoverse N2 DPU，具備 800Gbps 網路與 PCIe Gen5 支援）上安裝 Ubuntu LTS 的過程。此安裝展示 E1 可執行原生 Ubuntu，無須專有修改。這突顯在此先進資料中心 DPU 上部署標準 Linux 的可行性。
